# C++ Mini Compiler

## Installation and Execution

```bash
# Install required tools (Debian/Ubuntu)
sudo apt-get install flex bison g++ make

# for macOS, you can use Homebrew
brew install flex bison gcc make

# Clone the repository
git clone https://github.com/Arefin40/Mini-Compiler.git
cd Mini-Compiler

# Build and run the compiler
make

# Clean build artefacts
make clean
```
